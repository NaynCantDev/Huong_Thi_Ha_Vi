## Quy ước trong file .md

- Frontmatter: `title`, `slug`, `source_url`, `nav_order`, `parent`, `banner`.
- `<!-- LAYOUT: ... -->` mô tả bố cục gốc (cột, căn giữa, font).
- `<!-- IMAGE ... -->` / `<!-- EMBED ... -->` ghi vai trò ảnh và khối nhúng tại đúng vị trí.
- Văn bản tiếng Việt giữ nguyên như bản gốc, kể cả lỗi chính tả.
